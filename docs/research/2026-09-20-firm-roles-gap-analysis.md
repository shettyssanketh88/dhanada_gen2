# Roles real trading firms staff that the agent roster lacks — and which matter for a small autonomous Zerodha desk

*Research date: 2026-09-20. ~27 web calls (SEBI/NSE circulars, Zerodha/Kite Connect docs and forum, hedge-fund operations literature, SR 11-7, Indian tax guides, and the TradingAgents / FinCon / HedgeAgents / ai-hedge-fund / india-trade-cli repos). Feeds `specs/000-platform/roles.md` v2.2 and `compliance.md`.*

## Headline

The 15-role roster is heavier on **decision** roles (Scanner, Senior Analyst, CIO, Quant Researcher, Validation Reviewer, Coach) than any published multi-agent framework, but it is thin exactly where real firms are thick: **money and truth reconciliation** (margin/treasury, contract-note and ledger reconciliation, P&L attribution, tax ledger) and **order-level compliance** (pre-trade checks independent of execution, surveillance for PFUTP patterns). None of the five frameworks examined has any of those either; this comes from broker/exchange rules and from the middle/back office of real funds.

Two evidence points make these gaps concrete for an LLM-run desk:
- TradeTrap (arXiv 2512.02261) shows that a small corruption of account/ledger state propagates through the agent loop into "extreme concentration, runaway exposure, and large portfolio drawdowns" (one example: ~61% loss, 100% in one stock). The only defense is an independent reconciliation against broker truth. https://arxiv.org/abs/2512.02261
- v1's own incidents: quote-feed freezes from token collisions and a cost model that understated real costs 2.3× — middle/back-office failures, not alpha failures.

## What the multi-agent frameworks include

TradingAgents (analysts, bull/bear researchers, trader, risk debaters, PM; simulated exchange only), FinCon (manager–analyst, CVaR control, belief updates), HedgeAgents (fund manager + asset experts, conferences), virattt/ai-hedge-fund (persona analysts, risk manager, PM), india-trade-cli (7 analysts, bull/bear, facilitator, fund manager; VIX-scaled sizing; broker adapters; acknowledges static IP but has no margin, reconciliation, surveillance or tax function). None supplies the middle/back office.

## India-specific obligations to emulate

**Individual API trader** — static IP whitelisted for order endpoints; ≤ 10 orders/sec/client/exchange or register the strategy and carry an algo ID; non-zero market protection; ≤ 10 slices; daily 2FA re-login; algos hosted in India; broker keeps 5-year logs; IP sharing only within family. Zerodha's T&C state the APIs are "not meant for placing fully automating trades" without exchange approval — resolve with Zerodha compliance before running unattended.

**Registered entities (emulate, not register)** — Research Analyst: Principal Officer accountable for compliance, compliance officer, record-keeping. Broker: compliance officer with quarterly certificates, half-yearly internal audit, six-monthly system audit for algo systems, surveillance policy with 30-day alert disposition and quarterly reporting, kill switch, 8-year records.

Pattern worth copying: **an accountable principal officer (CIO), a compliance function split into a pre-trade gate and a post-trade auditor, a scheduled self-audit cadence (half-yearly), and a named kill-switch owner.**

## Ranked top 6 roles to add

1. **Treasury / Margin & Settlement Manager** — peak-margin snapshots, expiry and physical-settlement margins, cash and pledge moves.
2. **Books & Records / Reconciliation Agent** — positions, cash, fills vs Kite and contract notes; P&L attribution; tax ledger.
3. **Pre-trade Compliance Gate**, compliance-owned, independent of execution — static IP, 10 OPS, market protection, slicing, price bands, self-match across desks, MWPL, hours, blacklist.
4. **Execution Quality / TCA Analyst** — implementation shortfall per fill; calibrated cost model.
5. **Event & Corporate-Actions Calendar** (inside Data Ingestor).
6. **Security & Kill-Switch Owner** (explicit duties inside Operations Engineer).
