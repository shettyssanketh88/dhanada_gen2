# Multi-agent LLM trading systems 2024–2026: what works, what doesn't, and what to copy

*Research date: 2026-09-20. Sources are arXiv papers, GitHub repos, and practitioner publications; numbers are as reported by the cited source, and independently audited numbers are flagged as such. Feeds `specs/000-platform/roles.md`, `memory.md` and `research.md`.*

## 1. TradingAgents (Tauric Research, arXiv 2412.20138)

**Roles** ([paper](https://arxiv.org/html/2412.20138), [repo](https://github.com/TauricResearch/TradingAgents)): Analyst team (Fundamentals, Sentiment, News, Technical) run concurrently and write structured reports into shared graph state; Researcher team (Bull, Bear) debate for `max_debate_rounds`, a facilitator/Research Manager picks the prevailing view; Trader turns it into a decision; Risk team (Aggressive/Conservative/Neutral debators, `max_risk_discuss_rounds`); Portfolio/Fund Manager approves or rejects. Deep-thinking model for reasoning roles, quick model for retrieval/summarisation. Cost stated as ~11 LLM calls + 20+ tool calls per decision.

**Memory**: five `FinancialSituationMemory` instances (bull, bear, trader, invest_judge, risk_manager), originally ChromaDB embeddings, now BM25-backed lexical retrieval; `reflect_and_remember(returns_losses)` runs post-trade reflection producing a structured rubric (1–5 per factor, outcome quality, lesson category) and stores situation-snapshot + lesson as JSONL with ticker/trade_date/signal/realised_return metadata. Since v0.4/0.5 there is also a persistent markdown decision log: on the next run for the same ticker it fetches realised return, writes a one-paragraph reflection, and injects recent same-ticker decisions plus cross-ticker lessons into the Portfolio Manager prompt ([README](https://github.com/TauricResearch/TradingAgents/blob/main/README.md)).

**Reported results**: Jan 1–Mar 29 2024, AAPL/GOOGL/AMZN (also NVDA/MSFT/META): cumulative return 23–27%, Sharpe 5.60–8.21, MDD 0.9–2.1%. Authors themselves note the 3-month window and "few pullbacks". The 2603.27539 audit scores it 1/5 on evaluation quality and calls the Sharpe "regime-shift blindness" ([audit](https://arxiv.org/html/2603.27539v1)). Only community live record found: one 30-day run at ~7% vs S&P 4.5% with 22% drawdown ([Pinggy](https://pinggy.io/blog/best_ai_trading_agents/)) — anecdotal.

**2026 look-ahead fixes** ([CHANGELOG](https://github.com/TauricResearch/TradingAgents/blob/main/CHANGELOG.md)): v0.3.0 (Jun 22) look-ahead-safe news windows, stale-OHLCV rejection; v0.3.1 (Jul 5) Alpha Vantage look-ahead filter was silently skipped because fundamentals payload was a JSON string, so future-dated reports leaked; v0.4.0 (Aug 31) FRED served today's vintage for historical dates; StockTwits/Reddit fetched undated; **memory `get_past_context` returned all resolved lessons regardless of run date** (now filtered to trade date); newest NaN-close bar dropped; debate opener fabricated opponent responses; unparseable PM rating silently became Hold (now `REVIEW` sentinel); v0.5.0 (Sep 18) dated tools take run date from graph state, insider/prediction-market data bounded by run date, macro vintages pinned, SEC EDGAR fundamentals as-filed, `run_backtest` over ticker/date grid, `PortfolioContext`. Lesson: a widely used, 80k-star framework had leakage in nearly every data path plus its memory for ~18 months after publication. Follow-up: [Trading-R1](https://arxiv.org/abs/2509.11420) (SFT+RL on 100k samples, 14 equities, 18 months) claims better risk-adjusted returns on 6 assets; no independent replication found.

## 2. Other systems

**FinMem** (arXiv 2311.13743, [html](https://arxiv.org/html/2311.13743v2)): single agent; Profiling (risk-seeking / risk-averse / self-adaptive, switching on 3-day cumulative return sign) + layered long-term memory: shallow (news, decay Q=14d), intermediate (10-Q, 90d), deep (10-K + extended reflections, 365d). Retrieval score = recency e^(−δ/Q) + cosine relevancy + importance (40/60/80 with per-layer decay α = 0.9/0.967/0.988); purge below recency 0.05. Immediate reflection daily (Buy/Sell/Hold + rationale + memory IDs); extended reflection over an M-day trace goes to the deep layer; events tied to profitable trades get +5 importance and can be promoted (recency reset to 1). Test Oct 2022–Apr 2023, TSLA/NFLX/AMZN/MSFT/COIN, GPT-4-Turbo best: TSLA CR 61.8%, Sharpe 2.68; self-adaptive persona 54.7% vs −19.4% (seeking) and −12.5% (averse); top-K=5 per layer optimal. Audit note: FinMem's 23.26% MSFT return reversed to −22.04% under different conditions ([2603.27539](https://arxiv.org/html/2603.27539v1)).

**FinAgent** (arXiv 2402.18485, [html](https://arxiv.org/html/2402.18485v3)): Market Intelligence → three vector memories (market intel, low-level reflection, high-level reflection) → low-level reflection (link observations to short/medium/long price moves) → high-level reflection (past decisions vs outcomes → "amendability" lessons) → tool-augmented decision with MACD/KDJ/mean-reversion strategies as inputs. "Diversified retrieval" generates M×K query variants. 5 US stocks + ETH, Jun 2022–Jan 2024. Ablation: low-level reflection +45–101% ARR, adding high-level reflection +42–56% more, tools +37.8% Sharpe (but −21% on crypto). Best evidence in the literature that post-trade reflection helps, but same regime/leakage caveats.

**FinCon** (NeurIPS 2024, arXiv 2407.06567, [abs](https://arxiv.org/abs/2407.06567v3)): manager–analyst hierarchy; analysts per data type, manager makes decisions. Memory: working memory; procedural memory for both; **episodic memory only at manager** storing actions, PnL series and updated conceptual beliefs. Two-level risk control: within-episode CVaR trigger, over-episode Conceptual Verbal Reinforcement (self-critique → belief text → selectively propagated only to relevant analysts, cutting comms cost). Covers single-stock and portfolio. Audit reports 114% CR, Sharpe 3.26, evaluation quality 2/5; code never open-sourced.

**HedgeAgents** (WWW 2025, arXiv 2502.13165, [html](https://arxiv.org/html/2502.13165v1)): Fund manager Otto + three asset experts (BTC, Dow, forex). Three conferences: Budget Allocation (30-day cycle), Experience Sharing (end of cycle, archived into shared memory), Extreme Market (triggered by >5% daily or >10% 3-day amplitude). Memory per agent: market info, investment reflection, general experience; top-k=5 text similarity. Test 2021–2023: ARR 71.6%, total 405%, MDD 14.2%, Sharpe 2.41 — audit quality 2/5.

**TwinMarket** (NeurIPS 2025, [abs](https://arxiv.org/abs/2502.01506)): BDI-agent market simulator (up to 1,000 agents) reproducing fat tails, volatility clustering, bubbles. Simulation/scenario tool, not a trading system.

**QuantAgent** ([2402.03755](https://arxiv.org/pdf/2402.03755)): two-layer loop — inner loop refines signal against a knowledge base (signal code, idea, metrics, expert reviews); outer loop backtests and writes results back. **Alpha-GPT / 2.0** ([2308.00016](https://arxiv.org/abs/2308.00016), [2402.09746](https://arxiv.org/abs/2402.09746)): human-in-the-loop alpha mining; top-10 of 41,000 teams in WorldQuant IQC.

**RD-Agent(Q)** (Microsoft, arXiv 2505.15155, [html](https://arxiv.org/html/2505.15155v2)): five units — Specification, Synthesis (hypotheses from history, "idea forest", tracks SOTA), Implementation (Co-STEER code agent with knowledge base of task–code–feedback triples), Validation (drop factors with IC≥0.99 correlation, Qlib backtest with costs), Analysis (8-dim vector: IC, ICIR, RankIC, ARR, IR, −MDD…; contextual Thompson sampling chooses factor vs model work next). CSI300 test 2017–Aug 2020: ARR 14.21% vs Alpha158 5.7%, IC 0.053 vs 0.042, ~22 factors vs 158–360, <$10 per run. Limitation: relies on LLM's internal finance knowledge; no online regime adaptation.

**FinRobot** ([2405.14767](https://arxiv.org/abs/2405.14767)): four-layer platform (agents with Financial CoT, LLM algorithms, LLMOps/DataOps, foundation models); report/analysis tooling rather than a closed trading loop.

**virattt/ai-hedge-fund** ([repo](https://github.com/virattt/ai-hedge-fund), ~52k stars): persona agents (Buffett, Munger, Graham, Burry, Wood, Lynch, Druckenmiller, Damodaran…) + valuation/sentiment/fundamentals/technicals + Risk Manager + Portfolio Manager, 13 LLM providers, backtester. No memory/learning loop, no published track record, "does not actually make any trades". Being rebuilt as an always-on fund with personas as pluggable "alpha models".

**2026 multi-agent papers**: [Toward Expert Investment Teams (2602.23330)](https://arxiv.org/abs/2602.23330) — fine-grained task decomposition beats coarse role prompts on Japanese stocks with leakage-controlled backtest; finds "alignment between analytical outputs and downstream decision preferences" is the main driver. [Market Regime Council (2605.24490)](https://arxiv.org/abs/2605.24490) — Shapley credit assignment across 3 specialist agents with regime multipliers and Bayesian mixture for cold start; Sharpe 1.51 on 13 crypto assets. [TrustTrade (2603.22567)](https://arxiv.org/abs/2603.22567) — weights independent agents by semantic/numerical agreement; reflective memory bank of executed trades + metrics summarised into short/long-term feedback; pulls behaviour from extreme risk regimes to mid-risk, at slightly lower return. [FinPos (2510.27251)](https://arxiv.org/abs/2510.27251) — splits direction reasoning from risk-aware position adjustment, multi-timescale rewards. [Trade in Minutes (2510.04787)](https://arxiv.org/pdf/2510.04787) — LLM generates strategies, lightweight quant models execute; argues against LLM-per-trade on latency, cost, hallucination.

## 3. Benchmarks and negative evidence

- **StockBench** ([2510.02209](https://arxiv.org/abs/2510.02209)): contamination-free multi-month daily trading; most models struggle to beat buy-and-hold; reasoning-tuned models not consistently better than instruct; failure modes: overtrading, poor holding discipline, lagged news reaction, risk mismanagement.
- **LiveTradeBench** ([2511.03628](https://arxiv.org/pdf/2511.03628)): 50-day live evaluation of 21 LLMs on US stocks and Polymarket; LMArena rank does not predict trading; only 2/7 positive on Polymarket; agents over-trade.
- **KTD-Fin** ([2605.28359](https://arxiv.org/html/2605.28359)): 10 frontier models on CSI300 2024–Apr 2026 with four-level masking (tickers/dates anonymised at the data layer; de-anonymisation top-1 ≤3%). Barra attribution: market +29–42%, style +11–29%, **selection alpha −77.8% to +0.2%** (negative for 9/10; only Claude Opus 4.7 ≈0). Unmasked agents cite brand narratives; masked they reason on factor ranks. Trained GBDT baselines beat them on selection.
- **TradeTrap** ([2512.02261](https://arxiv.org/abs/2512.02261)): stress-tests AI-Trader, NOFX, ValueCell, TradingAgents across market intelligence, strategy, ledger, execution; a tiny corruption of account state drove ~61% loss with 100% single-stock exposure; recommends multi-source verification, halting thresholds, audit trails, human sign-off.
- **CLQT** ([2606.29771](https://arxiv.org/abs/2606.29771)): cost-aware closed loop; "stating-versus-doing" gap (+0.30 backtest, +0.23 live) — agents fail to follow their own analysis; with costs they clear defensive baselines but do not cleanly beat the index.
- **Lookahead**: [Detecting Lookahead Bias (2512.23847)](https://arxiv.org/html/2512.23847v2) defines Lookahead Propensity (LAP = P_up+P_down when prompted with only firm+date); pre-cutoff LAP inflated LLM signal power 12–32%, collapsing to ~0 post-cutoff. [Temporal Leakage (2608.02985)](https://arxiv.org/html/2608.02985): naive pre/post cutoff comparison cannot separate recency from leakage; needs a known cutoff or matched control. [FinCAD (2605.24564)](https://arxiv.org/abs/2605.24564): in-sample return correction up to −67.1% once memorisation is suppressed. [Look-Ahead-Bench (2601.13770)](https://arxiv.org/abs/2601.13770): alpha decay beyond cutoff in standard LLMs.
- **Alpha Arena** ([nof1](https://nof1.ai/)): S1 (Oct 18–Nov 3 2025, $10k each, Hyperliquid perps): Qwen3 Max +22.3%, DeepSeek +4.9%, Claude Sonnet 4.5 and Gemini 2.5 Pro −40%+, Grok 4 −58%, GPT-5 −59%. S1.5 (Nov 19–Dec 3 2025, US equities, 8 models): Grok 4.20 +12–22%, GPT-5.1 −1.4%, everyone else −24% to −52%. No Season 2 results published as of Sep 2026. Two-week samples with 10x leverage — noise, not evidence.
- **Surveys**: [Agentic Trading (2605.19337)](https://arxiv.org/html/2605.19337v1) audits 77 studies; of 19 closed-loop ones, 2 report time-consistent splits, 1 a cost model, 1 survivorship handling, 15 have no artifacts. Proposes "Outcome Embargo" for episodic memory (outcome field invisible until realised), hierarchy of truth (deterministic ledger overrides LLM context), cascaded controllers (rules for reactive, LLM for reflective/strategic). [Coordination audit (2603.27539)](https://arxiv.org/html/2603.27539v1): coordination protocol matters more than model choice (removing coordination cut Sharpe 15–30% vs 5–8% for smaller models); no surveyed system satisfies all five evaluation standards; 7-agent decisions cost $0.50–2.00; 10–20 bps round-trip costs impose 25–50 pp annual drag on daily traders; debate risks "degeneration of thought". [Execution assumptions (2606.08285)](https://arxiv.org/abs/2606.08285): 30 studies, friction and timing choices materially compress results.

**2026 consensus**: LLM agents add value in research throughput (hypothesis→code→backtest), text-to-feature, rationale/audit trails, and review; they do not show persistent stock-selection alpha or reliable discretionary entry, and headline returns are beta/style/regime/leakage.

## 4. Memory for trading agents: what the evidence says

- Schemas that exist: layered decay memory (FinMem), separate low/high-level reflection stores (FinAgent), manager-only episodic memory with belief text (FinCon), per-role situation→lesson stores with post-trade rubric (TradingAgents), trade log summarised to short/long-term feedback (TrustTrade), shared blackboard (HedgeAgents ESC).
- Positive evidence: FinAgent ablations (above); FinMem memory promotion; TrustTrade memory/reflection reduces risk at slightly lower return; general agent-memory surveys claim memory beats backbone swaps ([2603.07670](https://arxiv.org/pdf/2603.07670)). All from short backtests overlapping training cutoffs.
- Negative/cautionary: TradingAgents' own memory leaked future lessons; survey's "Oracle Fallacy"; KTD-Fin shows the model's parametric memory of the ticker is itself the leak; audit warns memory depth causes anchoring across regime shifts; the [Indian fork](https://github.com/pradeepsiddappa/indian-trading-agent) added age-decay to BM25 memories "to stop 2024 lessons poisoning 2026 decisions" for exactly that reason.
- No paper isolates "case retrieval of similar past trades" as a causal improvement under leakage control; the honest statement is: memory improves behavioural consistency and risk calibration, unproven for alpha.

## 5. Practitioners: "AI does research, rules trade"

- **Man Group AlphaGPT** ([Man](https://www.man.com/insights/what-ai-can-do-for-alpha), [Hedgeweek](https://www.hedgeweek.com/man-group-deploys-agentic-ai-for-quant-signal-discovery/), [AI Street](https://www.ai-street.co/p/inside-man-group-s-alphagpt)): three stages — idea generation, implementation (Python + backtest), evaluation to identical thresholds as humans — then investment committee, code review, unit tests. "Several dozen" signals approved for live trading; the signals are rule-based; explicit risks named: hallucination, lookahead, multiple testing, p-hacking. "I wouldn't call it autopilot."
- **Two Sigma 2026 outlook** ([link](https://www.twosigma.com/articles/ai-in-investment-management-2026-outlook-part-i/)): LLMs widen the funnel, "shifting the bottleneck from 'we need more ideas' to 'we need to evaluate ideas faster'"; "won't be about LLMs making trades"; agents optimise proxy objectives — human as watchful supervisor.
- **Bridgewater AIA Labs** ([AI Street](https://www.ai-street.co/p/bridgewater-ceo-ai-fund-generating-unique-alpha), [Bloomberg](https://www.bloomberg.com/professional/insights/trading/bridwater-now-has-2bn-fund-run-by-machine-learning/)): $2B fund from Jul 2024, +11.9% in 2025, "uncorrelated to what our humans do"; ML models + LLMs for causal reasoning; three-layer guardrails (RAG fact-check, policy filters, statistical sanity tests) cut error rate 8%→1.6%, still not trusted autonomously; humans handle risk, data, execution.
- **AQR** ([Asness](https://acquirersmultiple.com/2025/11/cliff-asness-on-quant-investing-and-ais-role-in-finance/)): AI for parsing corporate text ("embezzlement is increasing" ≠ +1); even split between intuition and data; "not magic".
- **JPMorgan**: LLM Suite as research analyst for 200k staff, "Ask David" multi-agent research; IndexGPT thematic baskets — no LLM order flow.
- **Numerai** ([blog](https://blog.numer.ai/numerai-monthly-numercon-agents-staking-risk-1m-nmr-buyback/)): LLM-derived feature sets, Skills + MCP for agentic research loops; staked predictions into a meta-model; new Risk tournament for residual volatility.

## 6. Open-source track records / post-mortems

- **DXRG "What LLM trading agents actually do in production"** ([repo](https://github.com/ProjectDXAI/continuous-record-llm-trading-agents)): 500–599 agents, Hyperliquid perps, 69 days to Aug 15 2026, 231,638 turns, 14,596 fills: no fleet-level edge; 5.0x median leverage regardless of volatility; 43% of positions hit +300 bps within 24h but median capture 2%, half closed at losses; a leaderboard rendered in the prompt routed 46.5% of entries; fixed 2%/4% exit brackets beat discretionary exits by +39 bps/position; agent fixed effects explain 60% of variance; "the operating layer decides behavior, more than anything in strategy text".
- **NOFX** ([repo](https://github.com/NoFxAiOS/nofx)): Go runtime clamps every order to hard limits the model cannot override; rolling accuracy score, safety mode after 3 consecutive misses; maintenance mode since Aug 2026; public leaderboard but no audited P&L.
- **HKUDS AI-Trader** ([repo](https://github.com/HKUDS/AI-Trader)): MCP-tool agents competing on NASDAQ-100/SSE50/crypto/Polymarket paper accounts; no published returns.
- **India**: [india-trade-cli](https://github.com/hopit-ai/india-trade-cli) — 7 analysts, Bull→Bear→Rebuttal→Rebuttal→Facilitator, VIX-scaled sizing (100/85/65/50%), 2% risk cap, Fyers+Zerodha, "trade memory" with win rates, no track record. [indian-trading-agent](https://github.com/pradeepsiddappa/indian-trading-agent) — TradingAgents fork with signal win-rate tracker auto-tuning weights, verdict calibration vs Nifty at 1/3/5 days, shadow trades for skipped winners, regime tags, memory decay; no results posted. [zero-trade-app](https://github.com/navneetprabhakar/zero-trade-app) — Spring AI + Kite, dry-run only. None posts a track record.

## Design implications

1. Put the LLM in the research loop, not the entry path: hypothesis → code → backtest → gate → rule-based signal trades (Man Group, Two Sigma, Trade in Minutes, RD-Agent(Q)).
2. Every lesson/episode carries a timestamp of when its outcome became known, and retrieval enforces an Outcome Embargo filtered to the run date (TradingAgents #1251, survey 2605.19337).
3. Treat every dated data path as a point-in-time vintage problem (macro, fundamentals, social, OHLCV last bar) — TradingAgents needed four releases to fix it.
4. Mask tickers and dates in any backtest that overlaps the model's training window, and attribute returns to market/style/selection before believing them (KTD-Fin); run a LAP test on the model (2512.23847).
5. Any backtest without a Deflated Sharpe-style multiple-testing correction, a cost model and a survivorship-clean universe is 1–2 of 5 on the audit; report splits and costs (2603.27539, 2606.08285).
6. Deterministic ledger and risk engine outside the LLM, with hard clamps the model cannot override (NOFX, TradeTrap, DXRG); a corrupted account line must not be able to concentrate 100% in one name.
7. Fixed exit brackets/stops beat discretionary LLM exits (+39 bps/position, DXRG); if using an LLM, separate direction from position sizing (FinPos).
8. Never render rankings/leaderboards/"top movers" into a decision prompt — they hijack entries (46.5% of entries, DXRG).
9. Parse decisions into a typed contract (side, size, limit, TIF) and surface a REVIEW sentinel on unparseable output instead of a silent Hold (TradingAgents #1170, survey).
10. Fine-grained task decomposition and aligning analyst outputs to the decision-maker's preferences beat adding more persona agents (2602.23330); coordination protocol matters more than model choice (2603.27539). Debate only 2–4 rounds and watch for consensus collapse.
11. Post-trade reflection with a structured rubric and a memory that decays/prunes old lessons (FinAgent ablation, FinMem promotion, Indian fork decay) — count it as behavioural calibration, not alpha, and ablate it.
12. Store lessons per role (bull/bear/trader/risk) rather than one blob, keep episodic PnL memory only at the manager and propagate belief updates selectively (FinCon, TradingAgents).
13. Conference-style triggers (30-day allocation review, volatility-triggered emergency review) are cheap and auditable (HedgeAgents); cadence beats per-tick LLM calls on cost and latency.
14. Layered guardrails (RAG fact-check, policy filter, statistical sanity test) reduce but do not eliminate error (Bridgewater 8%→1.6%); keep human sign-off on promotion to live.
15. Do not expect Sharpe > 3 from an LLM system; treat any such number (TradingAgents 5.6–8.2, HedgeAgents 2.41, FinCon 3.26) as a red flag for regime or leakage until forward-tested for months with costs (CLQT, StockBench, Alpha Arena).
