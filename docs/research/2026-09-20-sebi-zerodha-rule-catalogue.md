# Compliance rule catalogue — individual algo trader on Zerodha Kite Connect (NSE cash + index futures, defined-risk options)

*Research date 2026-09-20. ~40 web lookups; SEBI/NSE/Zerodha official pages preferred. Caveat: the Feb-2025 SEBI algo circular is served as a PDF; its clauses are reconstructed from SEBI's extension circulars, Zerodha's Z-Connect summary and Kite Connect forum notes. Items marked **[verify]** came from secondary sources only. Feeds `specs/000-platform/compliance.md` and `rails/market_rules/`.*

Timing keys: PO = pre-order, ID = intraday, EOD, W = weekly, P = periodic/on circular.

## Checks the compliance function must run

**Pre-order (synchronous, < 5 ms):** egress IP ∈ whitelist (A2/B5); OPS bucket < 10/s per segment and daily counters (A1/B5); tag present, ≤ 20 chars, strategy id encoded (A3/B7); session gate vs timings/holidays and product windows (A16/B1/B3); instrument checks — lot multiple, freeze qty (split to iceberg), price within band/LPP, `market_protection ≠ 0`, not in ban list unless delta-reducing (A8/A14/A15/B7); surveillance status — reject MIS/BTST on ASM/GSM/T2T/PCA/unsolicited-SMS, CNC only with 100 % margin (A7/B10); product rules — CNC sell ≤ free holdings, MIS on allowed list, no CO on options, options defined-risk only, no far-OTM NRML, no long OTM stock options ≤ 2 days to expiry, no stock F&O past E-4 without funding plan (B3/B4/A12); margin — required ≤ available with cash ≥ 50 % and ledger ≥ 0 (A10/B2/B9); PFUTP — no contra resting order that would self-match, cancel/modify ratio guard, no size > x % of scrip ADV, no price-setting orders in last 15 min (A6); signal provenance = exchange disclosure/verified data (A9).

**Intraday (every 1–5 min):** running OTR vs 50/250/500 slabs and 2000 alarm (A5); peak-margin headroom incl. MTM (A10); index-derivative FutEq delta vs limits (A13); T-minus timers for square-offs — close own MIS ≥ 5 min earlier (B1); ban-list intraday updates; 429/RMS rejection burst detector → halt strategy; kill-switch heartbeat.

**EOD:** reconcile orders/trades/positions vs broker; every order has tag + strategy version hash (A3/A4); margin report, expected penalty (A10); delivery obligations & T1 holdings (A11); stock F&O expiry exposure E-4 (A12); OTR final; cost ledger with correct STT (A18/B8); bulk-deal threshold (A17); archive logs.

**Weekly / periodic:** refresh MIS list, freeze qty, lot sizes, holiday calendar; static-IP change budget; confirm manual TOTP login each day (B6); quarterly settlement dates → pre-fund (A19/B9); monthly margin-shortfall instance count (< 5); FY turnover vs 44AB thresholds; verify strategy still < 10 OPS; re-register on logic change (A4).

**On circular:** subscribe to SEBI circulars (MRD/MIRSD), NSE circulars (SURV, F&O, CMTR), Zerodha bulletin/Z-Connect/Kite forum; diff rule catalogue; flag effective dates.
